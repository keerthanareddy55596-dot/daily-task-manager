# Daily Task Manager

A responsive To-Do List web app built with **HTML, CSS, and JavaScript**. Add daily tasks, choose a priority, track progress, and keep tasks saved in your browser.

## Features

- Add tasks with high, medium, or low priority
- Mark tasks as completed or active
- Filter tasks by All, Active, and Completed
- Delete individual tasks or clear all completed tasks
- Summary of total, completed, and remaining tasks
- Saves tasks with browser `localStorage`
- Responsive layout for desktop and mobile
- No installation or build tools required

## Project files

```text
daily-task-manager/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add a task and start organizing your day.

## Upload to GitHub

1. Create a repository named `daily-task-manager`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Commit your changes.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## Note

Tasks are saved only in the current browser on your device. Clearing browser site data may remove them.
